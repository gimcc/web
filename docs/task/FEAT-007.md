# FEAT-007 实现消息时间线（虚拟滚动、反向加载）

## 描述

使用 TanStack Virtual 实现消息时间线的虚拟滚动，支持可变高度消息、反向滚动（最新消息在底部）、向上滚动加载历史消息（分页）。

验收标准：
- 虚拟滚动渲染，千条消息无卡顿
- 可变高度消息正确计算
- 反向滚动（底部对齐）
- 向上滚动触发历史消息分页加载
- 新消息到达时自动滚动到底部（可配置）
- 滚动到底部的 "新消息" 提示按钮
