- **status**: done

- **owner**: claude-agent
- **createdAt**: 2026-03-16 17:30

## 描述

实现图片、视频、文件消息的上传和展示。包含统一上传流程（进度条、可取消）、缩略图预览、Lightbox 全屏查看、mxc:// URI 处理。

验收标准：
- 图片消息：缩略图显示、点击 Lightbox 查看原图、GIF 自动播放
- 视频消息：缩略图 + 播放按钮、内嵌播放器、流式播放
- 文件消息：MIME 图标 + 文件名 + 大小、点击下载
- 统一上传流程：文件选择 → MIME 校验 → 本地预览 → 上传进度条 → mxc:// URI
- 上传可取消（AbortController）
- E2EE 房间加密附件透明处理
- 大小限制遵循 homeserver m.upload.size
