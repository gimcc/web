# FEAT-084: Responsive Layout (Screen Adaptive)

## Summary
Make the chat layout fully responsive across mobile, tablet, and desktop screen sizes.

## Requirements
- Mobile-first responsive breakpoints
- Collapsible sidebar on small screens (already partially implemented)
- Stacked panels on narrow viewports
- Touch-friendly sizing
- Right panels (members, search, thread) as overlays on mobile
- i18n keys for en and zh-CN
