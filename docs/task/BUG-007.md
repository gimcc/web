# BUG-007 添加日期分割线与未读分割线

- **priority**: P1
- **status**: open
- **owner**: —
- **created**: 2026-03-20

## 问题描述

timeline 中没有日期分割线（Today / Yesterday / 具体日期），也没有未读消息分割线（"New Messages"），用户无法直观地区分不同天的消息和未读消息的起始位置。

## Cinny 做法

在 `eventRenderer` 渲染循环中计算：
- **日期分割线**: `!inSameDay(prevEvent.getTs(), mEvent.getTs())` → 插入日期 badge
- **未读分割线**: `prevEvent.getId() === readUptoEventId` → 插入 "New Messages" badge

两者都在事件 JSX 前插入，用 `React.Fragment` 包裹。

## 建议方案

在 `MessageTimeline` 的虚拟列表渲染中，遍历 messages 时比较相邻消息的时间戳和已读位置，插入分割线组件。
