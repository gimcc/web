# FEAT-024 实现 i18n 国际化支持

| 字段 | 值 |
|------|------|
| 状态 | 待办 |
| 优先级 | P2 |
| 创建日期 | 2026-03-17 |

## 背景

当前所有 UI 文本均为硬编码英文字符串，不支持多语言切换。需要引入 i18n 框架，将所有用户可见文本提取为翻译键，支持运行时语言切换。

## 目标

- 引入 i18n 框架（推荐 `react-i18next` + `i18next`）
- 提取所有组件中的硬编码文本为翻译键
- 支持至少英文（en）和中文（zh-CN）两种语言
- 语言偏好持久化到 `localStorage`
- 在设置 UI 的外观面板中添加语言切换选项
- 支持 Matrix 协议中的本地化内容（如房间名称、事件类型显示）

## 范围

- 所有 `apps/web` 中的 UI 组件
- 错误消息、状态文本、按钮标签、占位符
- 日期/时间格式本地化
- 不含 `packages/matrix-client`（纯逻辑层，无 UI 文本）

## 当前状态

- 无任何 i18n 基础设施
- 所有文本硬编码在 JSX 中
- 设置面板已有外观（Appearance）标签，可扩展语言选项
