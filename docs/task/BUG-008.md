# BUG-008 修复向上加载历史后滚动位置跳动

- **priority**: P2
- **status**: open
- **owner**: —
- **created**: 2026-03-20
- **parent**: BUG-003

## 问题描述

向上滚动触发 `loadRoomHistory()` 后，`setTimeline()` 全量替换数组导致所有 item 的 index 变化。`@tanstack/react-virtual` 没有锚点稳定机制，页面滚动位置会跳动。

## Cinny 做法

`recalibratePagination` 在分页后重新计算 range offset：
- 记录分页前的 timeline 事件数
- 分页后计算新增的 timeline 和事件数
- 调整 `range.start` 和 `range.end` 偏移量，保持可视内容不变

## 建议方案

1. 优先修复 BUG-003（改用 `prependMessages`）
2. 在 prepend 后记录原滚动位置，计算新增高度，调整 scrollTop
