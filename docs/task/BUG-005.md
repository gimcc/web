# BUG-005 补充缺失事件类型渲染

- **priority**: P1
- **status**: open
- **owner**: —
- **created**: 2026-03-20
- **parent**: BUG-001

## 问题描述

sync-bridge 和 timeline 组件只处理 `m.room.message` 类型事件。以下类型完全缺失：

| 事件类型 | 说明 | 用户可见影响 |
|----------|------|------------|
| `m.sticker` | 贴纸消息 | 贴纸不显示 |
| `m.room.member` | 成员变更（加入/退出/邀请/封禁） | 用户加入退出无提示 |
| `m.room.name` | 房间名变更 | 改名事件不显示 |
| `m.room.topic` | 房间主题变更 | 改主题事件不显示 |
| `m.room.avatar` | 房间头像变更 | 改头像事件不显示 |
| `m.room.encryption` | 加密启用 | 启用加密无提示 |

## Cinny 做法

`useMatrixEventRenderer` 按事件类型分发渲染：
- `m.room.message` → `<Message>` + `<RenderMessageContent>`
- `m.sticker` → `<Message>` + `<MSticker>`
- `m.room.member` → `<Event>` + `parseMemberEvent()`
- 其他 state event → `<Event>` + 通用展示
- 未知事件 → 仅 `showHiddenEvents` 时显示

## 建议方案

1. sync-bridge 中对更多事件类型做路由
2. 新增 `TimelineEvent` 泛型类型（不仅限于 message）
3. timeline 组件中按类型渲染不同 UI
