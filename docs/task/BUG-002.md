# BUG-002 实现双向 timeline 导航与事件跳转

- **priority**: P0
- **status**: done
- **owner**: —
- **created**: 2026-03-20
- **parent**: BUG-001

## 问题描述

当前 timeline 使用扁平 `TimelineMessage[]` 数组，无法支持：
- 点击回复消息跳转到原消息
- 通知深链接（打开特定 eventId）
- 从任意事件位置双向分页（forward + backward）

## Cinny 做法

Cinny 使用 SDK 的 `EventTimeline` 链式结构：
- `getLinkedTimelines()` 遍历双向链表收集完整 timeline 链
- `getEventIdAbsoluteIndex()` 从 eventId 反查绝对索引
- `useEventTimelineLoader` 通过 `mx.getEventTimeline()` 加载任意事件所在 timeline
- `ItemRange` 维护可视窗口，支持双向滚动

## 影响范围

- `packages/matrix-client/src/services/message-service.ts`
- `packages/matrix-client/src/stores/messages-store.ts`
- `apps/web/src/components/message-timeline.tsx`

## 建议方案

直接读取 SDK `EventTimeline` 对象，或在 store 中引入 timeline 链式引用而非扁平数组。
