- **status**: pending

## 描述

实现胁迫密码功能。输入预设胁迫密码后，表面正常解锁，实际静默擦除全部本地数据（DEK、IndexedDB、localStorage、sessionStorage、SW 缓存），最后显示"会话已过期"。

验收标准：
- 胁迫密码设置/修改/移除 UI（必须先有锁屏密码）
- 胁迫密码不能与正常密码相同
- 验证顺序：先正常密码 → 再胁迫密码（防误触发）
- 触发后伪装解锁动画 → 后台静默擦除 → 显示"会话已过期，请重新登录"
- 仅存储验证 hash（独立 salt），纯本地操作
- 离线可触发
