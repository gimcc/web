# BUG-009 优化 Store 订阅避免不必要重渲染

- **priority**: P2
- **status**: open
- **owner**: —
- **created**: 2026-03-20

## 问题描述

`MessageTimeline` 订阅方式：
```typescript
const timelines = useMessagesStore(s => s.timelines)
const messages = timelines.get(roomId) ?? EMPTY_TIMELINE
```

`s.timelines` 返回整个 Map 引用。当任何房间的 `appendMessages` / `setTimeline` 等操作创建新 Map 时，**所有订阅了 `s.timelines` 的组件都会重渲染**，即使当前房间的消息没有变化。

## 建议修复

改为精确订阅：
```typescript
const messages = useMessagesStore(s => s.timelines.get(roomId) ?? EMPTY_TIMELINE)
```

同理 `hasMore`：
```typescript
const hasMore = useMessagesStore(s => s.hasMore.get(roomId) ?? false)
```

注意：需要确保 `EMPTY_TIMELINE` 是稳定引用（当前已是模块级常量，OK）。
