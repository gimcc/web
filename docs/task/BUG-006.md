# BUG-006 实现消息折叠分组

- **priority**: P1
- **status**: open
- **owner**: —
- **created**: 2026-03-20

## 问题描述

同一发送者在短时间内连续发送的消息，每条都完整显示头像和用户名，视觉上非常冗余。

## Cinny 做法

判断是否折叠的条件（全部满足才折叠）：
1. 前一条消息已渲染（`isPrevRendered`）
2. 不跨日（`!dayDivider`）
3. 不跨未读线（`!newDivider` 或者发送者是自己）
4. 同一发送者（`prevEvent.getSender() === eventSender`）
5. 同一事件类型（`prevEvent.getType() === mEvent.getType()`）
6. 时间间隔 < 2 分钟（`minuteDifference(prevEvent.getTs(), mEvent.getTs()) < 2`）

折叠后不显示头像和用户名，只保留消息体和时间。

## 建议方案

在 `MessageTimeline` 的渲染循环中加入分组逻辑，传递 `collapsed` prop 给 `MessageBubble`。
