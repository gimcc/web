# BUG-004 添加 RoomEvent.TimelineRefresh 监听

- **priority**: P1
- **status**: open
- **owner**: —
- **created**: 2026-03-20
- **parent**: BUG-001

## 问题描述

SDK 在以下场景会触发 `RoomEvent.TimelineRefresh`：
- Sync 出现 gap（断网重连后有 limited timeline）
- SDK 内部重置 timeline 结构

当前 `sync-bridge.ts` 未监听此事件，导致 SDK timeline 已重置但 Zustand store 仍保留旧数据，UI 显示过期消息。

## Cinny 做法

```typescript
useLiveTimelineRefresh(room, useCallback(() => {
  if (liveTimelineLinked) {
    setTimeline(getInitialTimeline(room));
  }
}, [room, liveTimelineLinked]));
```

## 建议修复

在 `sync-bridge.ts` 中添加 `RoomEvent.TimelineRefresh` 监听，触发时调用 `loadInitialTimeline(room.roomId)` 重新加载 timeline。

## 影响文件

- `packages/matrix-client/src/sync/sync-bridge.ts`
