# BUG-011 完善加密消息非 message 类型处理

- **priority**: P2
- **status**: open
- **owner**: —
- **created**: 2026-03-20
- **parent**: BUG-001

## 问题描述

`sync-bridge.ts` 对 `m.room.encrypted` 事件等待 `MatrixEventEvent.Decrypted` 后调用 `processTimelineEvent()`，但该函数只处理 `m.room.message` / `m.reaction` / `m.room.redaction`。

如果加密事件解密后类型为 `m.sticker`、`m.room.member` 等，会被静默丢弃。

## 影响场景

- 加密房间中的贴纸消息不显示
- 加密房间中的成员变更不显示（如果房间配置了加密成员事件）

## 建议修复

在 `processTimelineEvent()` 中扩展处理更多事件类型，或在 BUG-005 修复后自然覆盖此问题。

## 影响文件

- `packages/matrix-client/src/sync/sync-bridge.ts`
