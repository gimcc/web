# FEAT-071: Message Layout Switch (Bubble/Compact/Modern)

## Summary
Allow users to switch between three message display layouts: bubble (WhatsApp-style, current default), compact (IRC-style dense), and modern (Slack-style with full-width rows).

## Requirements
- Add layout preference to appearance settings panel
- Store preference in localStorage
- Three layouts: bubble, compact, modern
- i18n keys for en and zh-CN
